# 日本の消費者物価指数の構造分析

## 分析目的
日本の物価上昇の推移を把握し、生鮮食品やエネルギー価格の変動と物価上昇の関係を検証する。

## 使用データ
- 出典：総務省統計局（e-Stat）
- 対象地域：全国
- 対象期間：2018年1月～2026年9月
- 基準年：2025年
- データ件数：315件

## 分析対象
- CPI：総合指数
- CCPI：生鮮食品を除く総合指数
- CCCPI：生鮮食品及びエネルギーを除く総合指数

## 分析内容
1. 消費者物価指数の時系列分析
2. 前年同月比の比較
3. 3系列の乖離分析
4. 年別の物価上昇率の比較

## 使用技術
- Python
- Pandas
- Plotly
- Deepnote
- PostgreSQL
- Docker
- e-Stat API

## 分析上の注意点
系列間の上昇率の差は、厳密な寄与度を示すものではない。
